# AI Resume Screening System

## 📌 Project Overview

The AI Resume Screening System is a web-based application that helps recruiters analyze and rank resumes based on a given job description.

The system extracts text from resumes, identifies relevant skills, compares resumes with job requirements, calculates a matching score, and ranks candidates automatically.

## 🎯 Objectives

- Automate the initial resume screening process.
- Extract important skills from resumes.
- Compare candidate skills with job requirements.
- Calculate resume-job similarity using TF-IDF.
- Generate a final candidate score.
- Identify shortlisted candidates.
- Rank multiple candidates.
- Store resume information in MySQL.

## 🚀 Features

- Resume upload
- PDF and DOCX text extraction
- Text preprocessing
- Skill extraction
- Job description analysis
- Skill matching
- TF-IDF text similarity
- Final score calculation
- Candidate shortlisting
- Multiple candidate ranking
- Recruiter dashboard

- Modern interactive user interface
